## 📚 **Chi tiết các môn học mới**

### 🆕 **Cơ sở dữ liệu** (màu teal)
**Chương 1: SQL cơ bản**
- Cơ bản: CREATE TABLE, INSERT, SELECT, WHERE, UPDATE/DELETE, ORDER BY, Aggregate functions, GROUP BY
- Nâng cao: Complex JOINs, Subqueries & CTEs, Window functions, Stored procedures

**Chương 2: Database Design**  
- Cơ bản: ERD, Normalization, Keys, Data types, Indexes, Constraints, Views, Backup
- Nâng cao: Partitioning, Replication, ACID properties, NoSQL patterns

### 📱 **Lập trình Mobile** (màu red)
**Chương 1: React Native cơ bản**
- Cơ bản: Setup, Components (View, Text, TouchableOpacity, TextInput, ScrollView, FlatList, Image), StyleSheet
- Nâng cao: Navigation, AsyncStorage, Camera & Gallery, Push notifications

**Chương 2: Native Features**
- Cơ bản: Geolocation, Sensors, File system, Network, Offline storage, Biometric auth, Deep linking, Background tasks
- Nâng cao: Native modules, Performance optimization, App store deployment, Cross-platform strategies

### ☁️ **DevOps và Cloud** (màu yellow)
**Chương 1: Docker và Containerization**
- Cơ bản: Installation, Dockerfile, Commands, Networking, Volumes, Compose, Environment variables, Monitoring
- Nâng cao: Kubernetes, CI/CD pipelines, Security, Microservices architecture

**Chương 2: Cloud Platforms**
- Cơ bản: AWS EC2, S3, RDS, Load balancers, Auto scaling, CloudWatch, IAM, VPC
- Nâng cao: Serverless Lambda, Infrastructure as Code, Multi-cloud, Cost optimization

## 🔧 **Mở rộng các môn hiện có**

### **Kỹ thuật lập trình** ✨ +1 chương
**Chương 3: Thuật toán và cấu trúc dữ liệu** (MỚI)
- Cơ bản: Linear/Binary search, Bubble/Selection sort, Stack/Queue, Recursion, Big O
- Nâng cao: Quick/Merge sort, Hash table, Binary Search Tree, Graph algorithms

### **Lập trình hướng đối tượng** ✨ +2 chương  
**Chương 2: Class và Object** (MỚI)
- Cơ bản: Class definition, Constructor/Destructor, Properties/Fields, Methods, Static members, Access modifiers, Object initialization, ToString override
- Nâng cao: Inheritance & Polymorphism, Abstract classes & Interfaces, Generics, Design patterns

**Chương 3: Collections và LINQ** (MỚI)
- Cơ bản: List<T>, Dictionary<K,V>, Array vs List, foreach, LINQ Where/Select/OrderBy/GroupBy/Aggregate
- Nâng cao: Custom LINQ extensions, IEnumerable vs IQueryable, PLINQ, Expression trees

### **Lập trình Back-end** ✨ +2 chương
**Chương 2: Database và ORM** (MỚI)  
- Cơ bản: SQL basics, JOINs, Sequelize setup/models/associations/migrations/seeders, Query optimization
- Nâng cao: Transactions, Connection pooling, Replication, Redis caching

**Chương 3: Authentication và Security** (MỚI)
- Cơ bản: Password hashing, JWT, Session management, CORS, Input validation, Rate limiting, HTTPS, Environment variables
- Nâng cao: OAuth 2.0, RBAC, API security, Penetration testing

### **Lập trình Front-end** ✨ +2 chương
**Chương 2: JavaScript ES6+** (MỚI)
- Cơ bản: let/const vs var, Arrow functions, Template literals, Destructuring, Spread/rest, Array methods, Promises/async-await, Modules
- Nâng cao: Closures, Prototypes, Event loop, Performance optimization

**Chương 3: React.js Framework** (MỚI)  
- Cơ bản: JSX, Functional components, Props/PropTypes, useState/useEffect, Event handling, Conditional rendering, Lists & keys
- Nâng cao: Custom hooks, Context API, React Router, Performance optimization
